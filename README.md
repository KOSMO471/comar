## 🇹🇷 Türkçe

**Çomar**, Windows, macOS ve Linux işletim sistemlerinde bilgisayarınızı bir köpek sadakatiyle koruyan, gereksiz dosyaları temizleyen, sistem bütünlüğünü onaran ve web üzerinden **uzaktan kontrol edilebilen** açık kaynaklı bir sistem bakım aracıdır.

### ✨ Öne Çıkan Özellikler
- 🖥️ **Çapraz Platform:** Windows, macOS ve Linux'u otomatik algılar ve uygun komutları çalıştırır.
- 🧹 **Akıllı Temizlik:** Geçici dosyaları (`TEMP`/`Cache`), tarayıcı önbelleklerini ve DNS kayıtlarını temizler.
- 🌐 **Uzaktan Web Kontrolü:** Uygulama içinden açabileceğiniz yerel sunucu ve tek kullanımlık güvenlik kodu (OTP) ile GitHub Pages üzerinden uzaktan yönetilebilir.
- 📦 **Toplu Güncelleme:** Paket yöneticileri (`winget`, `brew`, `apt`) üzerinden uygulamalarınızı güncel tutar.
- 🌓 **Koyu / Açık Tema:** Modern arayüz tasarımıyla göz yormayan karanlık mod desteği.
